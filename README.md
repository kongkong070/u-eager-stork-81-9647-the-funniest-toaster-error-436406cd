Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer.

## The line

> ERROR E-07: Toasting cancelled. The bagel was frozen, and frankly, so is our relationship.

(90 characters, one line.)

## How it works

`main.ts` (Node) validates the line against the kit gate (1–120 characters, single line, no control characters) and writes it to `/output/entry.txt`. The output directory is created when missing and never removed.
